GrowthOS V5 蓝色简约版

定位：个人大学成长管理系统

1. 全站改为蓝色简约风格，减少紫色渐变与装饰。
2. 保留左侧导航和多页面切换：首页、每日计划、工程管理、计算机路线、作业测评、成绩分析、创业项目、AI导师。

5. 支持每日任务打卡、学习记录、本地成绩记录、章节测试、成绩分析、创业任务。
6. 保留 ai_plan.php 接口，可在 PHP + MySQL + 登录环境下接入 AI 周学习计划。
